## DevOps Weekly Task 1
- Task 1: Learned about the basics of Git and the main command **git reset** with the flags **--soft --mixed --hard**
- **git reset --soft**: Moves history back. Your changes from the deleted commits are kept safe in your staging area, ready to be committed again
- **git reset --mixed**: Moves history back. Your changes from the deleted commits are kept safe in your working directory, but you have to **git add** them again.
- **git reset --hard**: **Destructive**. Moves history back and permanently deletes all changes in your working directory and staging area. Any uncommitted work will be lost forever.
